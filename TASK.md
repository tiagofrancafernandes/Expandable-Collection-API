# Product Goal

Build a multi-tenant dynamic database API similar to a programmable CMS/database platform.

Each tenant can create collections with custom schema.
The API returns structured JSON respecting the schema.

No frontend for now. API only.

Stack:
- Laravel
- PostgreSQL
- spatie/laravel-permission
- automated API documentation package
- automated tests required

Focus: performance and data isolation.

---

# Multi Tenancy

Each user owns projects.
Each project owns collections.
Each collection owns records.

Users must never access other tenants data.

Enforce:
- global scopes
- policies
- permission based access control

Super admin bypasses tenant scope.

---

# Collections

Collections have dynamic schema defined by user.

Supported types:
- scalar: int, float, boolean, string, null
- array/json
- reference to another collection
- internal_function generated values

Internal functions examples:
now()
uuid4
random int
random float
string random
range values

Generated fields must be resolved on insert.
